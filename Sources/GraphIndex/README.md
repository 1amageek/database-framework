# GraphIndex

`GraphIndex` executes property-graph and RDF-dataset declarations. These are
different semantic models and use different typed dispatch cases.

```swift
#Index(.graph(
    name: "social_edges",
    definition: .property(
        source: \Edge.source,
        label: .field(\Edge.label),
        target: \Edge.target,
        graph: \Edge.namespace,
        strategy: .adjacency
    ),
    includedFields: [\Edge.weight]
))
```

```swift
#Index(.graph(
    name: "statements_by_quad",
    definition: .rdf(
        subject: \Statement.subject,
        predicate: \Statement.predicate,
        object: \Statement.object,
        graph: \Statement.graph
    )
))
```

The module owns graph/RDF physical maintenance, graph readers, SPARQL source
execution, and graph algorithms. Ontology projection is selected by
`.graph(.ontologyProjection)` and is generated by ontology declarations.
Included fields preserve edge properties without changing graph identity.

Remote operation dispatch, paging envelopes, and host lifecycle are not owned
by this module.
